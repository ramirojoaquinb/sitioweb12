# Aura Pilates — Sitio demo (sitioweb12)

Sitio ficticio de demostración para **Aura Pilates – Estudio de Pilates** (Villa Crespo, Buenos Aires).

- `index.html`: landing de clase de prueba por WhatsApp en un solo archivo (sin build).
- Empresa 100% ficticia: dirección, teléfono `+54 9 11 5555-0278`, Instagram y links son de ejemplo.
- Para usar con un cliente real, editar solo el objeto `CONFIG` al final del `index.html`.
- El link de Maps acepta el enlace normal de "Compartir" de Google Maps (incluso el corto `maps.app.goo.gl`).
- El menú/planes se editan en `CONFIG.planes`; si el menú es un PDF, subirlo como `menu.pdf` y apuntar `menuUrl: "./menu.pdf"`.

## Probar local
Abrir `index.html` en el navegador o servir con `python -m http.server`.
